# Project Assumptions

## Assumptions Made

- The dataset is assumed to contain accurate marketing campaign data.
- ROI values are considered to be pre-calculated and valid.
- Revenue and Cost values are recorded in USD.
- Each CampaignID is unique.
- Campaign performance is evaluated independently.
- Missing values were handled during the data cleaning phase.
- All KPI calculations are based on the cleaned dataset.

## Limitations

- The project uses a sample dataset.
- External factors affecting campaign performance are not included.
- Customer demographic information is unavailable.

## Future Enhancements

- Integrate live marketing campaign data.
- Add predictive analytics for campaign performance.
- Build automated data refresh using Power BI.
- Develop machine learning models for campaign optimization.
